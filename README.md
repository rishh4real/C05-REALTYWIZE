# C05-REALTYWIZE

Static website for Realtywize, a land and plot advisory brand focused on Noida and NCR.

## Pages

- `index.html` - homepage with full-screen slideshow hero
- `about.html` - company positioning and promise
- `plots.html` - land and plot categories
- `contact.html` - WhatsApp, phone, and office contact details
- `privacy.html` - polished privacy policy
- `terms.html` - polished terms and conditions

Open `index.html` directly in a browser, or serve the folder with any static server.
